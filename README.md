# QA — Testes de API | Postman

## Sobre o projeto

Projeto prático de testes de API desenvolvido durante a formação em Quality Assurance na TripleTen.

## Atividades realizadas

- Elaboração de casos de teste para APIs;
- Envio e validação de requisições HTTP;
- Verificação de parâmetros e corpos de requisição;
- Validação dos códigos de estado HTTP;
- Comparação entre resultados esperados e obtidos;
- Testes com dados válidos, inválidos e de limite;
- Registo dos resultados dos testes;
- Identificação e documentação de defeitos no Jira.

## Ferramentas e conhecimentos

- HTTP

- Jira
